# The gate's sample of the movie library: what tools/suite.py runs by default
# (--all-movies runs the whole library). One movie a line, then after `#` why.
#
# Picked from the whole library's `--native shadow --coverage` runs: a greedy
# cover, each step taking the movie that adds the most code no movie before it
# ran (ROM code bytes and RAM instruction starts) per frame played, then the
# movies the checks need. Over the 53 movies of its making it keeps 96.2% of
# the library's ROM code bytes and 95.7% of its RAM instruction starts for 29%
# of the frames and 24% of the shadow runs' time. Left out are the long
# discovery movies (the Lavos endings but one, the tech sweeps, MotherBrain,
# the R Series, the Black Tyrano, Zeal), each of which adds at most 0.9% of the
# code for 4-15% of the time, and short ones whose code the sample already runs
# (the Magic Cave and after-the-fall movies, made to find ct_native's stops,
# add 0 and 15 bytes).
# The second batch of movies (84 in all) left the sample at 93.6% of the library's
# ROM instruction starts; the three below the cover, the best rates among the
# batch, bring it to 95.1%.
# Re-pick it when the library changes much (docs/MOVIES.md, "Adding it to the
# library"); the bytes below are what each added when it was picked, in order.
